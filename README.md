# MERN Stack Course - Beginner to Job-Ready

A complete, project-driven course covering the full MERN stack.Buiilt from absolute beginner level to production-ready applications.

## Projects

### Project 1 - Task Manager

> Status: In Progress

A browser-based task manager built with vanilla HTML, CSS and JavaScript.
Teaches: HTML structure, CSS Flexbox, JavaScript fundamentals, DOM manipulation, local storage.

### Project 2 - Blog Application

> Status: Not Started

Full-stack MERN application with authentication and payments.
Teaches: Node.js, Express, MongoDB, REST API design, JWT auth, Razorpay integration.

### Project 4 - Social Media Application

> Status: Not Started

Production-level application with real-time features and deployment.
Teaches: Advanced React, Concept API, file uploads, Socket.io, performance, deployment.
